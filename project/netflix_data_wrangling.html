Netflix Data Wrangling

A data-wrangling project focused on preparing a Netflix dataset for further analysis using Python and Pandas.

Project Objective

The objective of this project was to explore, structure, clean, enrich and validate the Netflix dataset before publishing the final cleaned dataset for future analysis.

Tools Used

  • Python
  • Pandas
  • NumPy
  • Kaggle Notebook

1. Discovery

The Discovery stage focused on understanding the Netflix dataset before making any changes.

The dataset was loaded into a Pandas DataFrame and inspected using functions such as head(), shape, info(), describe() and dtypes.

Missing values and duplicate records were also investigated to identify potential data-quality issues.

The analysis showed that director, country and cast were among the columns with the highest number of missing values.

2. Structure

The Structure stage focused on understanding and organizing the columns and data types in the dataset.

The dataset structure was examined using df.info() and df.dtypes. The column names were also reviewed to ensure they were clear and consistent.

The dataset contained information such as show ID, type, title, director, cast, country, date added, release year, rating, duration, genres and description.

3. Cleaning

The Cleaning stage focused on addressing data-quality issues identified during Discovery and Structure.

Missing values in selected columns were handled by replacing them with "Unknown". This allowed the records to be retained while clearly indicating unavailable information.

Duplicate records were also checked and removed where necessary.

Column names were standardized by removing unnecessary spaces, converting them to lowercase and replacing spaces with underscores.

4. Enriching

The Enriching stage focused on improving the usefulness of the dataset by preparing existing information for further analysis.

The categorical variables were examined using functions such as unique() and value_counts() to understand the different categories present in the dataset.

Data fields were reviewed to ensure that they could support future analysis and visualization.

No external dataset was added because the project was based on a single Netflix dataset.

5. Validating

The Validating stage was used to confirm that the data-cleaning and transformation steps had been successfully completed.

Missing values were checked again using df.isnull().sum().

Duplicate records were checked using df.duplicated().sum().

The dataset structure and data types were also reviewed again using df.info().

These checks helped confirm that the main data-quality issues identified during Discovery had been addressed.

6. Publishing

After completing the data-wrangling process, the cleaned dataset was exported as a CSV file.

File name: netflix_cleaned_data.csv

The completed notebook was saved on Kaggle, and the cleaned dataset was prepared for future analysis and visualization.

Results & Interpretation

The data-wrangling process improved the quality and consistency of the Netflix dataset. Missing values, duplicate records and formatting issues were identified and addressed.

The final dataset is more organized and suitable for further data analysis and visualization.

Conclusion

This project demonstrated the six main stages of data wrangling: Discovery, Structure, Cleaning, Enriching, Validating and Publishing.

The Netflix dataset was explored to understand its characteristics and identify data-quality issues. The dataset was then structured and cleaned, relevant fields were examined for enrichment, and validation checks were performed to confirm the quality of the final data.

The cleaned dataset was finally published as cleaned_netflix_data.csv and is ready for further analysis and visualization.
